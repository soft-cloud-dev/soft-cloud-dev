# Guides

Publish source-backed pages through the governed MyST pipeline.

## Publish your first page

1. Choose the appropriate documentation section and create an authoritative Markdown source.
2. Register the page once in the root [`myst.yml`](https://github.com/soft-cloud-dev/soft-cloud-dev/blob/main/myst.yml) `project.toc`.
3. Run the [`tools/check_profile.py`](https://github.com/soft-cloud-dev/soft-cloud-dev/blob/main/tools/check_profile.py) and the locked build before opening a pull request.
4. Check localized routes and translation provenance before publication.
