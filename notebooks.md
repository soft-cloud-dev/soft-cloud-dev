# Computational Notebooks

Notebooks are executable publication artifacts, not screenshots of unverified output.

## Verification notebooks

- [Computational verification](notebooks/experiment.ipynb) — checks the Python environment and execution profile.
- [Web Awesome documentation notebook](notebooks/webawesome-docs.ipynb) — exercises the UI integration documentation.

The [Architecture & Specification](architecture.md) defines the canonical environment and preflight controls. The [Contributor Guide](contributing.md) explains how to build and verify artifacts locally.

**Execution policy:** published results must come from the locked CI/build environment. A static example on the [handbook concept](handbook.md) is identified as a required profile rather than claimed as a live notebook result.
